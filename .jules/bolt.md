## 2026-09-30 - High-Throughput Log Analysis Hot Path Optimizations
**Learning:** In client-side log analyzers processing thousands of lines, inner-loop allocations like `Object.entries()` per line, `split().filter()` array creation, and eager array allocations for clean log lines dominate execution time. Hoisting static regular expressions, pre-flattening static signature objects, lazy-allocating arrays for flagged lines, and using standard `for` loops eliminates garbage collection overhead and dramatically improves throughput.
**Action:** When optimizing batch text/log scanning functions, avoid array callback abstractions (`.forEach`, `.filter`) and inner-loop object allocations (`Object.entries`); pre-flatten pattern lists and use lazy instantiation for match results.
